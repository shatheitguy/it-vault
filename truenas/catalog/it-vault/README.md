# IT-Vault

Self-hosted IT asset register and helpdesk: assets, employees, contracts,
tickets, a public request portal, LDAP/AD sync, network scanning, printable QR
labels and e-signed handovers. MariaDB is installed alongside it, so there is
nothing to set up first.
